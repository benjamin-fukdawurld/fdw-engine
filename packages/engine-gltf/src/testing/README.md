  assets (https://github.com/KhronosGroup/glTF-Sample-Assets, `Models/BoxTextured`),
  unmodified. © 2017 Cesium, under CC BY 4.0, as stated by the
  `LICENSE.md` of the model in that repository; its texture is the Cesium
  logo. Kept here as a reference file for the loader, not shipped.
