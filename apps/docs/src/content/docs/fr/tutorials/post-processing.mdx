La scène est dessinée dans une texture ; une passe plein écran la lit
ensuite, lui applique un virage sépia et assombrit ses coins, dans le canvas.

<Example name="post-processing" />

`renderer.render()` construit un petit render graph à chaque image et
l'exécute. Pour ajouter des passes, construisez le graphe vous-même : le
renderer ajoute ses passes à votre graphe, et un runner l'exécute.

## L'effet : un matériau plein écran

Un effet de post-traitement est un matériau dont le graphe se termine par
`fullscreen()` au lieu de `surface()`. Il calcule la couleur de chaque pixel
de la cible ; `builtin('screen-uv')` donne la position du pixel, de (0, 0) en
haut à gauche à (1, 1) en bas à droite, sur tous les backends.

```ts
const g = new GraphBuilder('sepia vignette');
const uv = g.builtin('screen-uv');
const color = g
  .call(std.textureSample, {
    texture: g.texture('scene'),
    sampler: g.sampler('sceneSampler'),
    uv,
  })
  .swizzle('rgb');

const gray = g.call(std.dot, { a: color, b: [0.299, 0.587, 0.114] });
const sepia = g.call(std.mul, { a: gray, b: [1.07, 0.74, 0.43] });
const toned = g.call(std.mix, {
  a: color,
  b: sepia,
  t: g.uniform('amount', BuiltinTypes.f32),
});
const distance = g.call(std.length, { x: g.call(std.sub, { a: uv, b: 0.5 }) });
// 1 up to 0.3 from the center, 0 from 0.8.
const vignette = g.call(std.sub, {
  a: 1,
  b: g.call(std.smoothstep, { low: 0.3, high: 0.8, x: distance }),
});
g.fullscreen({
  color: g.call(std.extend, {
    xyz: g.call(std.mul, { a: toned, b: vignette }),
  }),
});

const effect = new Material({
  graph: g.build(),
  values: { sceneSampler: backend.textures.createSampler() },
});
```

Sa texture `scene` n'est pas définie ici : c'est le render graph qui la lie.

## L'image comme render graph

```ts
const runner = new RenderGraphRunner(backend);

onFrame(() => {
  const graph = new RenderGraph();
  const output = graph.importTexture('surface', surface.getCurrentTarget());
  const scene = renderer.addScenePasses(graph, {
    items,
    camera,
    lights: [sun],
    target: graph.createTexture('scene', { format: 'rgba8unorm' }),
    format: 'rgba8unorm',
  });
  renderer.addFullscreenPass(graph, 'sepia vignette', {
    material: effect,
    inputs: { scene },
    target: output,
    format: surface.format,
  });
  runner.execute(graph);
  surface.present();
});
```

- `importTexture` fait entrer une texture gérée en dehors du graphe : l'image
  de la surface. L'écrire est la raison d'être de l'image.
- `createTexture` déclare une texture **transitoire** : le runner l'alloue à
  l'exécution de l'image, à partir d'un pool. Par défaut, elle a la taille de
  l'image, c'est-à-dire celle de la première texture importée.
- `addScenePasses` ajoute les passes de la scène (ombres, opaques,
  transparents) qui dessinent dans la cible, et renvoie la **version** de la
  cible qu'elles écrivent. Une passe qui lit cette version s'exécute après
  elles.
- `addFullscreenPass` dessine l'effet ; `inputs` lie sa texture `scene` à la
  texture écrite par la scène.
- `runner.execute` compile le graphe — ordonne les passes, élimine celles dont
  personne ne lit les résultats, alloue les textures — et enregistre l'image.

Construire le graphe à chaque image ne coûte presque rien : sa compilation est
mise en cache selon sa structure, et ses textures reviennent du pool. Les deux
ne sont refaits que lorsque la structure change (une passe ajoutée, la surface
redimensionnée).

## Enchaîner les effets

Chaque effet lit la version écrite par le précédent :

```ts
const blurred = renderer.addFullscreenPass(graph, 'blur', {
  material: blur,
  inputs: { source: scene },
  target: graph.createTexture('blurred', {
    format: 'rgba8unorm',
    size: { relative: 0.5 },
  }),
  format: 'rgba8unorm',
});
renderer.addFullscreenPass(graph, 'bloom', {
  material: bloom,
  inputs: { scene, blurred },
  target: output,
  format: surface.format,
});
```

`size: { relative: 0.5 }` correspond à la moitié de la taille de l'image.

:::note[Couleurs linéaires]
Ici, la scène est encodée en sRGB au moment où elle est dessinée : l'effet
travaille donc sur des couleurs encodées. Pour les effets qui ont besoin de
valeurs de lumière (bloom, exposition), dessinez la scène avec `linear: true`
dans une texture `rgba16float`, et appliquez le tone mapping dans le dernier
effet. `backend.capabilities.renderableFormats` indique si le backend peut
faire le rendu dans `rgba16float`.
:::
